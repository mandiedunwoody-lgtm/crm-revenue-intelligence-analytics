## Project Overview

This project analyzes a simulated CRM pipeline dataset to uncover revenue drivers, conversion bottlenecks, churn risks, and automation opportunities.  
It demonstrates how CRM systems can be used to improve sales performance, retention, and forecasting accuracy — skills essential for high‑paying Data Analyst, Revenue Analyst, and RevOps roles.

---

## Dataset

The dataset includes:

- Lead → Qualified → Opportunity → Closed Won/Lost  
- Deal size & revenue  
- Sales cycle length  
- Lead source  
- Region & industry  
- Sales rep performance  
- Renewal dates  
- Churn flags  
- Customer lifetime value (CLV)

Stored in:  
`/data/crm_pipeline.csv`
